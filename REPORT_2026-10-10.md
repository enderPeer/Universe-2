# Universe 2: status report, 10 October 2026

**Exhaustive sweeps of tiny machines, from instruction sets to a DNA-like world in which self-replicators arise by
themselves.**

Author: enderPeer. Repository: Universe 2 (local; predecessors on GitHub, linked below). Every number in this report
is a count produced by a program and checked against an independent implementation; nothing is estimated unless it
says so.

---

## 1. Summary

Universe 2 continues three projects that asked one question: *what do all the short programs of a tiny machine
compute?* This round answered four further questions.

1. **Real instruction sets.** Of all 2^32 four-byte words, **35.5509 %** are valid AArch64 instructions and
   **22.4648 %** decode completely as x86-64. Both figures are exact, from a full census.
2. **Two-bit instructions are enough.** Over all 58,905 four-instruction machines with 2-bit instructions, the best
   one computes **2,930,290** distinct 4-bit functions from its 2^32 programs. That is 1.6 times the best machine of
   the predecessor project at the same program size, with no register at all.
3. **A DNA-like machine.** Four letters, complementary strands, a 64-codon genetic code onto 20 operations, and
   genome-sized worlds of **3 billion cells** on a single GPU. The first version (DNA-1) could copy but not sustain
   a lineage. Three measured fixes (DNA-2) give self-replicators from **5 codons** on and
   **10.7 million** replicators among the 68.7 billion 7-codon genes. Populations persist **17,923 generations**
   with 98.3 % faithful copies.
4. **Origin without a seed.** In unseeded random worlds, self-sustaining replicators **arise by themselves**. Under
   the standard genetic code every world tested so far was taken over, after about **35,000 ticks** on average.
   Under a code without synonyms this takes about 100 times longer.

### The DNA machine as it stands (DNA-2)

- **Alphabet.** A, C, G, T as 2-bit symbols; the complement is `s xor 3` (A-T, C-G). The world tape has two
  strands, and the second repairs damage to the first.
- **Genes.** The tape is cut into slots of 1,024 cells (341 codons). A slot whose first codon is ATG is a gene,
  read in codons up to the first stop codon.
- **Genetic code.** The 64 codons map onto 20 operations plus STOP, with the standard code's degeneracy (for
  example, the six Leu codons). The operations are COPY, TERM (copy terminator), ALLOC (claim a slot for a child),
  DIVIDE, head moves, skips and loops, an accumulator, SEEK (find a template) and a reverse-complement copy.
- **Processor.** Each gene gets a processor holding a head, a template pointer, a write pointer and an
  accumulator. It runs 16 instructions per tick and lives 64 ticks. The copy pointers live in the processor, not
  in the genome.
- **World.** Each tick has eight deterministic steps: execute, resolve claims, births, deaths, damage, repair,
  random inflow into dead slots, and census. Mutation applies per copied cell. Every random choice is a seeded
  function of tick and index, so any run can be replayed bit for bit.
- **Verification.** The GPU engines give the same state hash as the Python reference on every tick of every test
  world: 9 world configurations, and 901 genes with 108,512 tick hashes in the sweep engine.

## 4. Findings

### 4.1 Real instruction sets: how much of the encoding space is an instruction?

| instruction set | 4-byte words that are an instruction | basis |
|---|---:|---|
| ARM32 | 86.8 % | sample, 16.8 M words |
| MIPS64 | 79.7 % | sample |
| PowerPC64 | 76.9 % | sample |
| RISC-V with compressed instructions | 57.4 % | sample |
| SPARC | 52.6 % | sample |
| **AArch64** | **35.5509 %** (1,526,900,218 words, 1,298 mnemonics) | exact, all 2^32 |
| **x86-64** | **22.4648 %** whole instruction sequences (940 mnemonics) | exact, all 2^32 |
| RISC-V without compressed instructions | 7.1 % | sample (by design: 75 % of the space is reserved for other lengths) |
| NANO, Universe-1, universe7, the 2-bit machines, the genetic code | 100 % | by construction |

One curiosity of the exact x86-64 run: exactly 2^24 words consist of four one-byte instructions, so x86-64 has
exactly 64 one-byte instructions. Each exhaustive census took about 15 minutes on one workstation.

### 4.2 Two-bit machines

A one-symbol instruction has no operand, so it can only move the head, change the cell under it, do both ("pens"),
branch on that cell, or use an implicit accumulator. The catalog has 36 such operations, so there are
C(36, 4) = 58,905 machines with four instructions. Each machine ran all 1.4 million programs of 1 to 10 symbols on
four cluster nodes, 165 billion program runs per score.

| score | best machine | result |
|---|---|---|
| distinct drawings from a blank tape | 12 machines (1-bit cells), 47 (2-bit cells), all made of pens | **perfect**: every one of the 1,396,636 distinct programs draws a different tape |
| distinct functions of a 4-bit input, 10 symbols | `L1, INC_L1, FLIP_R2, JNZB` | 274,601 functions = 19.6 % of all programs |
| the same, all 2^32 programs of 16 symbols | `L1, INC_L1, FLIP_R3, JNZB` | **2,930,290** functions (Universe-1 champion: 1,829,051; JC: 8,533,818) |

- **One conditional decides everything.** Each of the 500 best function machines has exactly one: a two-instruction
  loop or a skip. Machines without one never exceed 2,438 functions. The Turing-complete machine of Böhm (P'', the
  ancestor of Brainfuck) ranks 2,628th.
- **Drawing and computing are opposites.** The perfect drawing machines compute only 5 to 10 functions.
- **The libraries differ in shape.** The 2-bit library is Boolean-shaped: 99.9 % of its functions depend on all
  four input bits, and only 3 of the 16 constants occur. The champion's library is arithmetic-shaped, with every
  affine map.
- **A machine built from "eat, mate, sleep, excrete" computes little.** It ranks in the top 10 % at short lengths
  but saturates at 16,855 functions over 5.7 billion programs, because eating and excreting destroy what they read.

### 4.3 DNA-1: copying without life

| measurement | result |
|---|---|
| random world, 2,999,999,488 cells, 600,000 ticks (25 min on the RTX 4090) | 6,585,887 births, **3 faithful copies**, no lineage beyond one generation |
| every gene of 2 to 7 codons in a small world (68.7 billion at 7 codons) | first intact self-replicators at **7 codons**: 2,304 genes, two operation sequences, each making **one child only** |
| those replicators planted in the big world (1 million seeds) | geometric decay, ratio 0.33 to 0.50 per generation, **extinct after 14 generations**; one child per parent in 499,306 divisions |

The diagnosis was measured, not assumed. The copy loop stopped on whatever lay in the next slot, and after one
division the template pointer pointed past the gene for good. The same limit, one child per parent, had stopped
every replicator in the earlier projects.

### 4.4 DNA-2: three fixes, and life persists

**The fixes**, behind a flag, so DNA-1 still reproduces bit for bit:

1. **TERM**, on codons TTA and TTG, skips the next codon unless the copy has just passed a stop codon. It is the
   copy terminator.
2. **DIVIDE** resets the template pointer, so the same loop can copy again.
3. **COPY** does nothing while no child slot is claimed. Fix 2 needs this.

**The smallest replicator** is now `ATG GCT CTT TTA GGT` (START ALLOC COPY TERM DIVIDE).

| genes swept, every gene of each length | intact self-replicators, DNA-2 | DNA-1 |
|---|---:|---:|
| 5 codons (16.8 million) | 768 | 0 |
| 6 codons (1.07 billion) | 120,624 | 0 |
| 7 codons (68.7 billion) | **10,733,760** (one gene in 6,400) | 2,304 |

Every DNA-2 replicator has grandchildren, and seeds make 3 to 5 children in the small test world. That number is
the limit of the 8-slot test world, not of the genes.

| world | result |
|---|---|
| 3 x 10^9 cells, 1 million seeds, 600,000 ticks, 39 min on the RTX 4090 | **2.67 million organisms** hold 91 % of the slots throughout; **25.4 billion births, 98.3 % faithful**; lineages **17,923 generations** deep |
| six seeded 10^8-cell worlds, 50,000 ticks each (mutation 0.001 and 0.01, small slots, no second strand with 10x damage, uniform code) | every population holds about 91 % of the world for about 1,540 generations; 84 % to 98 % of births faithful |

- **Without a task, evolution only drifts.** Every leading gene in 3,000 censuses has the seed's five operations;
  only the codon spellings change. Copying is the only thing rewarded, and the seed is already the fastest copier.
- **The degeneracy of the genetic code matters.** The standard code gives **60 to 130 times more** replicators than
  a code with one codon per operation, at every length tested.

### 4.5 Origin: replicators arise from random material

Unseeded worlds of 10^8 cells start from random soup with random genes flowing into dead slots, 23 per tick, and
run up to 200,000 ticks. A world counts as **taken over** when a single lineage fills more than half of it.
Partial results: 37 of 96 runs are done; the queue finishes this evening.

| code | runs done | taken over | mean waiting time (95 % interval) |
|---|---:|---:|---|
| standard | 17 | **17** | **34,987 ticks** (21,851 to 60,094), about 800,000 random genes |
| uniform (no synonyms) | 20 | 1 | about 4 million ticks (at least 716,000) |

- **Different seeds give different winners.** In 17 standard-code worlds, 10 different operation sequences
  founded the winning lineage. Only one, `START COPY ALLOC TERM DIVIDE`, won twice. Founders range from 5 to 13
  codons, for example `START SKNZ TERM DIVIDE R3 SKNZ L1 COPY R1 ALLOC L3` and
  `START ALLOC COPY SKZ SKZ TERM DIVIDE`.
- **Takeover times vary widely**, from tick 799 to tick 149,199. In some runs a one-shot copier appeared long
  before the lineage that took over.
- **The waiting time matches the sweep.** About 800,000 random genes per origin agrees with the replicator density
  measured among short genes.
- **The code ratio matches too.** Standard against uniform is about 100 to 1 in waiting time, close to the 60 to
  130 to 1 ratio in replicator counts.

In the four projects, this is the first time a self-sustaining replicator originated in a world rather than being
written or searched for. Every run is deterministic: the moment of origin can be replayed and traced instruction by
instruction.

### 4.6 Related result from the same week

The best 2-bit function machine with 2-bit cells (`INC_R1, INC_L1, FLIP_R2, JNZB`) has **no multiply-accumulate**
acc + w·x mod 4 in any program of up to 16 symbols, at any step budget up to 512. That is 5.7 billion programs per
encoding, checked on the cluster's CPUs and GPUs; details in docs/13 and docs/14. Such an operation has to come from
composing programs or from a richer instruction.

## 5. What these results do and do not show

- **Designed chemistry.** The DNA machine's instruction set is our design, and TERM was added precisely so that copy
  loops can end. The origin result is about replication arising in a chemistry built to permit it, not in a neutral
  one.
- **Emulated CPUs.** The real-ISA execution classes come from an emulator (QEMU via Unicorn) from one fixed state,
  so they describe the architecture as modelled, not a physical chip. Five of the eight density figures are samples
  from one decoder (Capstone).
- **Function counts depend on conventions.** The comparison with Universe-1 uses different step budgets (64 against
  256) and different input placement (tape against register).
- **Origin statistics are still running.** The numbers in 4.5 are interim; the final ones go into docs/16.
- **No selection yet.** Evolution in the DNA worlds has nothing to select for except copying. A world with tasks is
  the next layer.

## 6. Next steps

1. Finish the origin statistics (96 worlds) and trace the founders' copy mechanisms instruction by instruction.
2. **A task layer.** Genes compute functions on a working tape (the 2-bit function library supplies the "proteins"),

## 7. Reproducing

Python 3.11+ with `capstone unicorn numpy`; for the engines, `nvcc` (CUDA 12) and gcc with OpenMP.

```bash
python sim/dna_ref.py --dna2 --N 2048 --G 256 --ticks 64 --blank --D 0 --F 0 --mu 0 --genome "ATG GCT CTT TTA GGT" --n-seed 1 --census-every 8
nvcc -O3 -std=c++17 -arch=sm_89 -o dna_world gpu/dna_world.cu
./dna_world --dna2 --N 2999999488 --G 1024 --ticks 600000 --seed 1 --no-hash --census-every 200 --n-seed 1000000 --genome ATGGCTCTTTTAGGT --mu 0.001
python tools/isa4_census.py --arch both --range 0 4294967296
```
